# Збирач інтерактивних уроків

Кожен урок — це один самодостатній `index.html` у форматі сайту CurrentLesson
(вчитель: `?role=teacher`, учні — без параметрів).

- `engine.css`, `engine.js` — рушій із прикладу CurrentLesson (синхронізація вчитель→учні, QR, салют, звук, смайлики).
- `widgets.css`, `widgets.js` — спільні ігри: вікторина, сортування по кошиках, сцена «знайди», загадки-літери, таймер, малювалка.
- `template.html` — каркас сторінки.
- `lessons/LXX.html` — зміст уроку: блок META (назва, папка для результату), слайди і скрипт уроку.

Зібрати всі уроки:

    py build.py

Лише один урок:

    py build.py L02

Результат:
- уроки → `<N>-klas/urok-<NN>/index.html` у корені репозиторію (шлях задає `out` у META);
- `shell.html` → `index.html` у корені репозиторію (головна сторінка: каталог для вчителя, екран учня);
- `lessons.json` — список усіх уроків, які лежать у папках репозиторію
  (сюди потрапляють і уроки, зроблені не збирачем, якщо покласти їх у таку саму папку).

Після збирання — закомітити й запушити репозиторій, і через хвилину-дві все буде на GitHub Pages.

## Поступова подача (кроки вчителя)

Будь-якому елементу слайда можна додати `data-step="1"`, `data-step="2"`… Такі елементи приховані,
доки вчитель не натисне «Далі» (кнопка тоді називається «Показати ще ⬇»). Учні бачать рівно те,
що відкрив учитель. Назад — ховає останній крок; повернення на попередній слайд показує його повністю.

## Старі уроки (3 і 4 клас)

Оригінали лежать у `legacy/`, налаштування — у `legacy/legacy.json`:
- `engine`: `nush4` (рушій прикладу CurrentLesson) або `nush3` (рушій уроку 8 для 3 класу);
- `rules`: які частини слайдів відкриваються кроками (`"номер слайда": ["CSS-селектор кроку 1", "кроку 2"]`).

`build.py` накладає на них латки з `patches.py` (кроки, QR на головну сторінку) і стилі `legacy-big.css` (великі кнопки).
