# CLAUDE.md — контекст для продовження роботи

Репозиторій сайту інтерактивних уроків інформатики (НУШ, 2–4 клас) для вчительки.
Сайт: GitHub Pages, https://girlscrush.github.io/CurrentLesson/ (гілка `master`).
Спілкування з користувачкою — українською.

## Як працює сайт

- **Учні** завжди відкривають одне посилання `https://girlscrush.github.io/CurrentLesson/` —
  бачать урок, який учитель зробив поточним (у iframe), або екран очікування.
  Запасний варіант без учителя: `?lesson=2-klas/urok-08/`.
- **Вчитель** відкриває `?role=teacher` — каталог класів і уроків (з `lessons.json`),
  кнопка «Зробити поточним», далі — керування презентацією (урок у iframe з `?role=teacher`).
- Синхронізація: MQTT по WSS на публічних брокерах (emqx, hivemq, mosquitto одночасно)
  + BroadcastChannel між вкладками.
  - Поточний урок: retained-повідомлення в топіку `informatyka_shell_<fnv(ROOT)>/current`,
    `{lesson, title, cls, ts}`; новіший `ts` перемагає; учитель перепубліковує кожні 20 с.
  - Стан уроку: retained `{slide, step, followMode, ts}`, топік = FNV-хеш чистої URL уроку.
- Кожен урок — **один самодостатній `index.html`** (інлайн CSS/JS, шрифт Nunito, звуки Web Audio,
  падаючі смайлики й салют на canvas, QR-код для учнів).

## Структура

```
index.html            головна сторінка (оболонка) — ГЕНЕРУЄТЬСЯ з _builder/shell.html
lessons.json          список уроків — ГЕНЕРУЄТЬСЯ скануванням папок
<N>-klas/urok-<NN>/index.html   уроки — ГЕНЕРУЮТЬСЯ (не редагувати руками!)
_builder/             збирач (Jekyll не публікує папки з «_», тож на сайті його не видно)
  build.py            збирання: `py build.py` (усе) або `py build.py L09` (один урок, без legacy)
  template.html       каркас сторінки уроку
  engine.js/.css      рушій із оригінального прикладу (синхронізація, QR, салют, звук)
  patches.py          латки рушія: кроки (step), QR на головну сторінку в iframe, захист від
                      вмикання режиму вчителя в iframe. patch_nush4 — рушій 2/4 класу, patch_nush3 — 3 класу
  widgets.js/.css     спільні ігри-віджети (див. нижче) + блок «великі кнопки»
  steps.js/.css       поступова подача (`data-step`)
  legacy/             оригінали старих уроків (4 клас урок 9, 3 клас урок 8) + legacy.json з правилами кроків
  legacy-big.css      великі кнопки для старих рушіїв
  lessons/LNN.html    ДЖЕРЕЛА уроків 2 класу — редагувати тут
  tools/extract.py    витягує текст із конспектів .docx/.pptx → _sources/ (у .gitignore)
  tools/outline.py    друкує структуру слайдів зібраного уроку
```

Формат джерела уроку `_builder/lessons/LNN.html`:
```
<!--META
{ "title": "Урок 11 • Робочий стіл комп’ютера (2 клас НУШ)", "pill": "НУШ • 2 КЛАС",
  "brand": "Урок 11: Робочий стіл комп’ютера", "emojis": ["🖥️", ...],
  "topic": "nush2-urok11-robochyi-stil", "out": "2-klas/urok-11/index.html" }
-->
<!--SLIDES-->
  <section class="slide active" data-slide="1"> ... </section>
  <section class="slide" data-slide="2"> ... </section>
<!--SCRIPT-->
  ...JS уроку (виклики віджетів)...
```
`out` — шлях відносно кореня репозиторію. `topic` — унікальний для кожного уроку.
Найкращий зразок для нового уроку — скопіювати `L11.html` / `L10.html` і замінити зміст.

Після будь-якої зміни: `cd _builder && py build.py` (повне збирання оновлює і legacy, і index.html, і lessons.json).
У Windows-консолі для українського виводу: `$env:PYTHONIOENCODING='utf8'` (з `py -I` змінна ігнорується).

## Віджети (`_builder/widgets.js`)

- `toggleMission(el)` — чекліст `.mission-item` (лічильник `.mission-status`).
- `flipCard(card)`, `openTile(tile)` — картки, що перевертаються / плитки.
- `reveal(btn)` — кнопка-підказка, показує `data-answer`.
- `makeQuiz(id, questions, {options, big, label})` — вікторина.
- `makeSorter(id, [{t,b}], [{id,label,bg,border,color}])` — сортування по кошиках.
- `makeScene(id, [{e,x,y,size,msg,label,target}], {fb,counter,counterText,mode:'good'|'remove',onDone})` — «знайди на картинці».
- `buildRiddle(containerId, word, onSolved)` → `{showAnswer()}` — слово-загадка по літерах (кросворд).
- `makeOrder(id, steps, opts)` — розстав кроки по порядку (підійде для алгоритмів, уроки 23–26).
- Таймер фізкультхвилинки: `startBreakTimer/pauseBreakTimer/resetBreakTimer`, хук `timerOnTick`.
- `showTab(btn, groupId, tabId)`; малювалка `initDraw(canvasId, templateFn)`, `setBrushColor`,
  `stampSticker`, `clearDrawCanvas`, `downloadDrawing(name)`; `pickReflection(btn, label)`.
- Класи: `.t-only.teacher-note` — підказка лише для вчителя (практичні роботи, посилання на
  LearningApps/GCompris); `.desk-sim`, `.sim-window` тощо — симулятор Робочого стола (урок 11);
  симулятор ПК і смартфона — в скрипті уроку 10.

## Правила оформлення (вимоги користувачки — обов’язково)

1. **Усі кнопки, які натискають учні, — великі й добре виділені** (стилі вже в widgets.css /
   legacy-big.css: мін. висота 52–78 px, 3D-тінь, пульсація для `.reveal-btn`, 👆 на чеклістах).
2. **Слайди не перевантажені.** Якщо інформації багато — видавати поступово: `data-step="1"`,
   `data-step="2"`… Елемент прихований, доки вчитель не натисне «Показати ще ⬇»; учні бачать рівно те,
   що відкрив учитель. Для старих уроків — правила в `legacy/legacy.json` (`"номер слайда": ["селектор кроку 1", ...]`).
3. Слайд має вміщатися в екран **1366×768** без прокрутки; якщо не вміщається — розбити на два слайди.
4. Якщо урок здебільшого з ребусів/логічних загадок — **об’єднати з наступним**, залишивши 2–3 загадки.
   Ребуси й кросворди скорочувати до 2–3 слів.
5. Типовий урок: ~11 слайдів — титул із «Пригадаймо», розминка, 2–4 інтерактивні пояснення/ігри,
   фізкультхвилинка з таймером, практика (симулятор/гра мишею), підсумок/рефлексія.
   Практичну роботу з конспекту — у `.t-only` підказку вчителю.

## Перевірка

```
py -I -m http.server 8765 --bind 127.0.0.1      # з кореня репозиторію
```
- `http://127.0.0.1:8765/?role=teacher` і в іншій вкладці `http://127.0.0.1:8765/` — перевірити «Зробити поточним»,
  перемикання слайдів і кроків у учня.
- Кожен новий урок: вікно 1366×768, пройти всі слайди, немає помилок у консолі, немає переповнення слайда.
