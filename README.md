# Інформатика — інтерактивні уроки

- **Учні:** https://girlscrush.github.io/CurrentLesson/ — показує урок, який учитель зробив поточним (або екран очікування).
- **Вчитель:** https://girlscrush.github.io/CurrentLesson/?role=teacher — список класів і уроків, кнопка «Зробити поточним», керування презентацією.

Уроки лежать у папках `<клас>-klas/urok-<номер>/index.html`, список — у `lessons.json`.
Обидва файли генерує збирач `_lesson-builder/build.py` (поза репозиторієм).
